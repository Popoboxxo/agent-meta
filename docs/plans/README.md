# docs/plans/

Aktive, vorwärtsgerichtete Pläne und Audits bleiben direkt in `docs/plans/`.

Abgeschlossene Reports/Audits (`## STATUS` bzw. `STATUS:` → `done`) wandern nach
`docs/plans/archive/`, sobald sie erledigt sind — sie bleiben als historische
Referenz erhalten, sind aber nicht mehr aktiv relevant.

Ausnahme: Ein Quelldokument, das noch aktiv referenziert/verlinkt wird (z.B. als
Grundlage für laufende Folge-Arbeit), bleibt trotz `STATUS: done` in `docs/plans/`,
bis diese Referenz nicht mehr gebraucht wird.
