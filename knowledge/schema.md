# Knowledge Schema — personal

> Generated by agent-meta knowledge-engine. Defines the concept types available
> in this knowledge bundle. Not automatically regenerated on domain change —
> see sync.py log output for a warning if the domain was switched after this
> file was first created.

## Domain

`personal`

## Concept Types

- person
- event
- place
- memory

## Usage

Each concept type above maps to a Markdown file under `knowledge/wiki/concepts/<type>/`.
Entities, topics and sources are tracked separately under `knowledge/wiki/entities/`,
`knowledge/wiki/topics/` and `knowledge/wiki/sources/`. `knowledge/wiki/index.md` is the entry point;
`knowledge/wiki/log.md` is the append-only change log.
